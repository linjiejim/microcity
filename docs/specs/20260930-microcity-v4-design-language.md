# MicroCity v4：新的视觉语言与信息减法

- 日期：2026-09-30
- 状态：done（用户看过两轮概念图，选定 A+B+C 组合，要求写完方案即开工；2026-09-30 落地并部署到演示站）
- 依赖：[v3 经典案例与分享](20260930-microcity-v3-classic-cases-and-sharing.md)（D1–D52 沿用；前端规则由本文 D53–D61 取代）
- 范围：只改前端（apps/web）与广场卡片的数据（`gallery.json` 加可选的 `figure`）：
  - 放弃像素风，换成“暖色纸面 + 深青强调”的视觉语言；
  - 城市：暖色微缩小镇（3D）+ 平面地图（2D），可切换；
  - 信息减法：每个工作区默认只回答一个问题，其余收进二级；
  - 广场与复盘改成“结论先行”的数据新闻版式。
- 明确不做：改内核（场景颜色、指标、事件）、改接口、改实验结论、新功能、英文界面、手机版专门布局（只保证窄屏不崩）

## 1. 背景与目标

用户的反馈：像素风不够现代友好；希望更精致、直观、易用，信息不要过多。

现状的问题：
- **像素风本身**：12 px 像素字体读中文吃力；深紫底色加阶梯描边显得粗糙；字体包 600 KB。
- **信息过载**：
  - 观察页的顶栏有二十多个控件（5 档倍速、单步、+10 分、快进到、发布新闻、诊断……）；
  - 现场叙事默认显示全部节拍；
  - 人物卡一次铺开七八块；
  - 反应墙的卡片挂满徽章。
- **结论藏得深**：广场卡片是一段文字，对照页先给表格，再给判定。

两轮概念图（`docs/assets/v4/`）确定的方向：

| 方向 | 用在哪 | 概念图 |
| --- | --- | --- |
| A 暖色微缩模型 | 观察的城市（默认视图）、设计页的预览 | [观察](../assets/v4/e2-observe.jpg)、[设计](../assets/v4/e4-design.jpg) |
| B 极简平面地图 | 观察的“地图”视图：分析用、窄屏用 | 同上，左上角“小镇 / 地图”切换 |
| C 数据新闻 | 广场、复盘的对照 | [广场](../assets/v4/e1-gallery.jpg)、[复盘](../assets/v4/e3-review.jpg)、[手机](../assets/v4/e5-mobile.jpg) |

目标：
1. 第一次来的人不看说明，也知道每一屏在讲什么、下一步点哪里。
2. 不删任何功能，只把它们挪到该在的层级。
3. 端到端测试照常守着：`data-testid` 保留；控件挪进菜单的地方，测试改成先打开菜单。

## 2. 设计

### 2.1 视觉语言（取代像素设计系统）

**颜色**（`theme/tokens.css`；canvas 与三维场景从 `theme/palette.ts` 取同一套值）：

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 纸面 | `#FAF7F2` | 页面底色 |
| 卡片 | `#FFFFFF`，次级 `#F3EEE6` | 面板、输入框、悬停 |
| 线 | `#E7E0D5` / `#D8CFC1` | 分隔、描边 |
| 墨 | `#26241F` / `#5E5A52` / `#8F897E` | 正文 / 次要 / 弱化 |
| 强调 | 深青 `#1F5F63`（浅底 `#E3EFEE`） | 主按钮、选中、“相信了” |
| 辅助 | 琥珀 `#E3A13A`（浅底 `#FBEFD8`） | “听说了”、提醒 |
| 语义 | 好 `#3E8E63`、坏 `#C2553A`、信息 `#4B7EAD`、谣言 `#A45A8A` | 判定、后果 |

- **状态三色**（城市、地图、图例统一）：还不知道 `#BDB6AA`，听说了 `#E3A13A`（瞥见、怀疑、不信），相信了 `#1F5F63`（相信、改了安排、照做了）。同一时间，颜色只表示这一件事。
- **渠道色、时段精度色**：保留原有语义，换成同一色系的低饱和版本。

**字体**：
- 正文用系统无衬线（苹方、冬青黑体、微软雅黑、思源黑体），14 px；
- 标题用系统衬线（宋体、思源宋体），缺失时回落无衬线；
- 字号阶梯 12 / 13 / 14 / 16 / 20 / 24 / 32；数字用等宽数字。

**形状**：
- 圆角 6 / 10 / 14 px，胶囊按钮 999；
- 描边 1 px；阴影是柔和的模糊阴影，分三级；
- 过渡 150 ms 缓动；尊重“减少动态效果”的系统设置。

**图标**：`ui/icons.ts` 改成 24×24 的线性图标（描边 1.75），名字不变，调用点不用改；城市里的头顶图标用同一套路径画到 canvas 上。

### 2.2 城市：暖色微缩小镇（A）与平面地图（B）

**3D 小镇**（沿用 `city/*` 的结构，只换材质、造型和光照）：
- **地形**：去掉 16×16 像素纹理，每类瓦片一个低饱和纯色（草地鼠尾草绿、道路暖灰、水面雾蓝、广场砂色）；地基改成土层色的“浮空底座”。
- **建筑**：墙面用线性过滤的高分辨率纹理（圆角窗格、门）；住宅和小店用坡屋顶，大楼用平屋顶加女儿墙。建筑配色由前端把内核给的颜色映射到暖色系（`palette.ts` 的映射表），**不改内核**（D56）。
- **人物**：方块小人改成圆润的“棋子”（胶囊身体 + 球形头，衣服颜色取自映射表）；脚下一个状态圆盘，颜色表示知情三态；选中时外圈加一道深青描边环。
- **光照**：标准材质、柔和阴影、抗锯齿、ACES 色调映射；昼夜关键帧改成柔和版：夜里是深蓝灰而不是黑，停电的区域明显更暗，有电的窗户透出暖光。
- **传播连线**：平滑的弧线，颜色按渠道。

**平面地图**（新增 `city/FlatMap.tsx`，SVG）：
- 俯视；瓦片按类型合并成色块，建筑是圆角矩形，居民是圆点（颜色表示知情三态），近期的转述画成细弧线；
- 点圆点选中居民，与 3D 共用 `selectedAgent`；
- 不需要 WebGL：窄屏、低性能设备、截图都用它。

**切换与图例**：
- 城市左上角一个分段控件“小镇 / 地图”（`store.cityMode`，记住上次的选择）；
- 左下角的图例只有三项状态（原来的渠道图例移进“显示”菜单）；
- 屋顶、标签、传播、跟随这几个开关收进一个“显示”菜单；缩放按钮只在 3D 时出现。

### 2.3 信息减法：每个工作区只回答一个问题

| 工作区 | 默认回答的问题 | 默认看得到的 | 收进二级的 |
| --- | --- | --- | --- |
| 广场 | 这个说法在小镇里成立吗？ | 示意图、问题、三个猜测按钮；猜完出现答案、带数字的图、判定、重跑 / 复制 | 经典出处、小镇规格、seed 数 |
| 设计 | 我要一座什么样的镇、发一条什么样的通知？ | 描述框与建议标签、小镇预览、剧本（每轮一张卡：时间、渠道开关、虚惊开关）、“开始观察” | 模板、人口与关系网参数、对话记录、对照实验 |
| 观察 | 消息此刻传到哪了？ | 城市、一个大数字（知道的人 / 总人数）、关键节拍（最多 5 条）、下一件剧本里的事、底部关键时刻 | 全部节拍与筛选、居民与新闻列表、倍速 / 单步 / 快进、发布新闻 |
| 复盘 | 发生了什么变化，为什么？ | 对照：问题 + 预测判定 + 核心指标；反应墙：每人一张卡（至多 2 个标记、3 行变化） | 逐 seed 配对、全部指标、分组方式、社会与报告页的细节 |

**顶栏**：
- 左边是品牌，中间是四个工作区；
- 观察时右边只有“运行名 · 播放 / 暂停 · 模拟时间 · 更多”；
- “更多”是一个弹层，放倍速、单步、+10 分、快进到、发布新闻（testid 不变）；
- 诊断和帮助是两个图标按钮；演示站标记改成一段不抢眼的文字。

**观察的右栏**：
- “现场”页顶部：大数字，下面一条三色进度条；
- 节拍默认只看“关键”，最多 5 条，“查看全部”展开原来的完整列表和筛选；
- “居民”“新闻”两页保留，降为次级标签。

**人物卡**：
- 默认只有头部、三行（在做什么、知道什么、因此做了什么）和想法；
- 信任、经历、最近的事收进“更多”折叠，“完整档案”按钮不变。

**底部章节条**：只标关键时刻（通知、半数相信、停电、来电、澄清、谣言），悬停看细节；“明细”打开原来的完整时间轴。

### 2.4 广场与复盘：结论先行（C）

**广场卡片**：
- 顶部一张示意图，下面是衬线标题和一句问题；
- 猜测按钮在猜之前**全部是中性色**（概念图里正确选项提前着色，是需要避免的反例）；
- 猜完才显示：答案一句、带数字的图、判定清单（规则 / Jev 的判定标签）、“在这里重跑”和“复制并修改”。

**示意图的数据**：`GalleryEntry.figure`（可选），由 `scripts/lab/gallery.ts` 写入，数字取自实验记录（D59）。支持三种：

```ts
type GalleryFigure =
  | { kind: 'dots'; total: number; unit: string; a: { label: string; value: number }; b: { label: string; value: number }; note: string } // 两张点图对比
  | { kind: 'race'; unit: string; rows: Array<{ label: string; a: number; b: number; aText: string; bText: string }>; aLabel: string; bLabel: string; note: string } // 两组人、两个条件下的快慢
  | { kind: 'chain'; rows: Array<{ label: string; values: number[] }>; note: string }; // 每一手的保留比例
```

**复盘 · 对照**：
- 顶部是问题（衬线大标题）和预测判定（每条一行：一句话 + 规则 / Jev 标签）；
- 下面是核心指标卡；“全部指标”“逐 seed 配对”默认折叠。

**图表**：canvas 图从像素阶梯改成抗锯齿折线和面积图，配色从 `palette.ts` 取。

## 3. 验收

1. **像素风已移除**：界面里不再有像素字体、Endesga 调色板变量、`steps()` 过渡和 `pixelated` 渲染（检索 `Fusion Pixel`、`--e-`、`steps(`、`pixelated` 只剩在迁移映射表里）。
2. **观察页默认信息**：城市、“小镇 / 地图”切换、三项图例、一个大数字、至多 5 条关键节拍、底部关键时刻；顶栏的倍速等控件在“更多”里，功能照旧。
3. **两种视图共用选择**：点 3D 小人或地图圆点都能选中居民并打开人物卡；两种视图的状态颜色一致。
4. **人物卡**：默认只有三行与想法；“更多”展开信任与经历；“完整档案”照常打开抽屉。
5. **广场**：猜之前按钮是中性色；猜完出现答案、示意图与判定；重跑、看结果、复制并修改照常（端到端）。
6. **测试**：`pnpm check` 全过；`pnpm e2e` 全过（只在控件挪进菜单处改了测试步骤）；全程没有页面错误。
7. **首屏**：进入广场时不请求三维引擎的代码块；首页不再下载像素字体。
8. **截图更新**：README 与 `docs/assets` 的截图换成新界面。

## 4. 决定

- **D53 放弃像素风，改用“暖色纸面 + 深青强调”的视觉语言。**
  - 用户看过四个方向的概念图后，选了 A（暖色微缩）+ B（平面地图）+ C（数据新闻）的组合。
  - 否决 D（深色控制台）：偏工程师工具，与“邀请更多人来做实验”的目标不合，三维光效的成本也最高。
  - 否决“只换皮、不减信息”：信息过载是用户的主要不满之一。
- **D54 城市有两种视图：3D 微缩小镇（默认）和平面地图；颜色同一时间只表示一件事（默认是知情三态）。**
  - 3D 有温度，平面图清楚、便宜、窄屏友好，两者互补。
  - 否决在 3D 里叠更多图层：60 个小人的脚下已经是可读性的上限。
- **D55 渐进披露：每个工作区默认只回答一个问题，控件收进“更多”，分析收进二级；不删功能。**
  - 否决删掉低频功能（倍速、单步、全部节拍）：做实验和写测试都要用到。
- **D56 前端映射颜色，不改内核给的场景颜色。**
  - 内核里建筑和人物的颜色是渲染提示；改了会动到生成场景、`town30` 等价测试与黄金哈希。
  - 映射表放在 `theme/palette.ts`，按原色查新色，查不到时做降饱和加提亮处理。
- **D57 线性图标取代位图图标，图标名不变。**
  - 调用点一处都不用改。
  - 否决引入图标库：多一个依赖，而头顶图标要画到 canvas 上，还得自己转路径。
- **D58 用系统字体，不打包网页字体。**
  - 中文字体包动辄几 MB；衬线标题用系统宋体，缺失时回落无衬线。
  - 否决按标题用到的字做子集化：标题会随实验内容变化，每次都得重新生成子集。
- **D59 广场的示意图由 `gallery.json` 的 `figure` 字段驱动，数字来自实验记录。**
  - 卡片在实验还没跑过时也要能显示；和卡片文字一样经代码评审。
  - 否决前端从实验结果现算：精选实验不一定跑过，而且结果里没有“点图”需要的汇总口径。
- **D60 城市按需分包，第一次进入观察才加载。**
  - 广场是演示站的首页，访客多半先看广场；三维引擎占首包的大头。
- **D61 AGENTS.md 的前端规则改写为新的设计规范。**
  - 颜色只用 `tokens.css` 的变量，canvas 与 3D 用 `palette.ts`；图标只用 `ui/icons.ts`；组件用 `ui/kit.tsx`；
  - 每个工作区默认只回答一个问题。

## 6. 落地记录

2026-09-30 本地完成；用户确认后推送，GitHub 上 CI 与部署都通过，演示站已换成新界面（线上验证：首屏只加载主包，进入观察才请求三维城市的包，控制台无报错）。

**做了什么**
- 设计变量、组件库、线性图标重写；像素字体依赖去掉；`palette.ts` 统一 canvas 与 3D 的配色，并映射内核的场景颜色。
- 城市：纯色地形、圆角窗与坡屋顶、圆润的小人与知情圆盘、柔和昼夜；新增平面地图与“小镇 / 地图”切换。
- 观察：顶栏的低频控件收进“更多”；现场改为大数字 + 关键节拍；人物卡默认三行；章节条改成细轨道。
- 广场：先猜后揭晓的卡片与示意图；复盘：对照结论先行、反应墙减法、图表抗锯齿；设计：三栏重排、剧本开关。
- 城市按需分包。

**验证**
- `pnpm check`：类型检查、lint、97 个单元与接口测试（1 个真实调用用例默认跳过）；
- `pnpm e2e`：19 个全部通过（只改了一处步骤：倍速、单步、快进、发布新闻先打开“更多”）；
- 生产构建：首屏 JS 从 1.5 MB（gzip 429 KB）降到 560 KB（gzip 182 KB），另省 600 KB 像素字体；三维城市拆成 947 KB 的独立包，第一次进入观察才加载；
- 四个工作区、弹窗与抽屉在 1440×900 下截图检查。

**与方案的差异**
- 广场示意图从三种变成五种：“渠道 vs 措辞”和“信任文化”两张卡要表达的是稳健度和两种心智的分歧，另加了稳健度条与正负分叉条。
- 现场默认“只列关键节拍”，没有硬截到 5 条：快进到发布后，“发布”和“第一个相信”都要看得到（端到端测试也依赖这一点）。
- three.js 0.186 已移除 `PCFSoftShadowMap`，改用 PCF 阴影加 `shadow-radius` 柔化。
- 设计页的小镇预览仍是 2D（圆角色块），没有做成概念图里的 3D 小模型：预览要随参数实时刷新，2D 更轻。

**留下的**
- 手机与窄屏：只保证不崩（最小宽度 1100 px），没有专门的窄屏布局。
