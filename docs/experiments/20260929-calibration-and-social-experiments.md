# 校准与社会实验（v2）

- 日期：2026-09-29
- 状态：done（假设写于任何一次运行之前并单独提交（仓库公开时开发历史压缩成了一个提交，原提交已不可查）；结果与洞察追加在第 5、6 节，第 2–4 节没有回改；S4b、S5b、S7 是看了结果之后加的探索性实验，已标明）
- 平台：MicroCity v1 + 规则参数化（[v2 方案](../specs/20260929-microcity-v2-calibration.md)）
- 边界：这是合成人物的沙盘，所有结论都是“这个模型下的结论”，不是现实政策效应。

## 1. 为什么先校准

v1 结束时有三个悬而未决的问题：
- 效用权重、传播概率、信任幅度都是手设的：结论会不会只是参数的产物？
- 规则决策与 Jev 决策差多少？3 个 seed 显示 Jev 的过度调整少得多。
- 两轮实验里信任会变，但第二轮行为几乎不变：是机制本来如此，还是幅度设小了？

所以顺序是：先校准（C1–C4），再用校准后的模型做社会实验（S1–S6）。

## 2. 方法约定

**两种“心智”**：
- 规则：确定、免费，每次运行 0.05–0.2 秒，可以跑很多 seed、很多座镇；
- Jev：语义因子来自 `typesafe/jev-1.13`，有花费，只在关键实验上跑。

**重复**：
- 规则模式：3 座实验镇（生成种子 42 / 7 / 99）× 每座 20 个运行 seed = 60 次重复；
- Jev 模式：实验镇 42 × 10 个 seed。

**实验标准镇（60 人）**：
- 生成底座，河分南北（约 31/29 人）；
- 老人、青年各 25%，订推送 30%，常看网站 25%，公告栏 2 块，对官方的平均信任 0.62；
- 剧本 E1：北区周四（D04）14:00–16:00 停电；D03 08:05 在网站、推送、公告栏发通知，标题只写“下午”（正文有精确时段）。

**比较**：
- 同一座镇、同一个 seed 的分支两两配对，看配对差的中位数和“方向一致的比例”。
- 判定规则事先定好：
  - 预测方向在 ≥ 70% 的配对里成立（60 对时约相当于符号检验 p < 0.01），记为“支持”；
  - ≤ 50%，记为“不支持”；
  - 介于两者之间，记为“部分支持”。
- 交互作用看逐对的“差中差”，判定规则相同。

**主要指标**（每一轮停电各算一套）：
- 半数人相信用时 t50；
- 停电时已知情、知道精确时段、信“全天”的人数；
- 信过“全天”的人数（谣言触达）；
- 措手不及的人数；
- 过度调整（分钟）：挪掉的安排里，落在真实停电时段或停电区之外的部分；
- 停电区外改了安排的人数（外溢）；
- 听到但不信、上网查证过的人数；
- 对官方信任的平均变化。

**判定细则**（在第一次运行社会实验之前补充，与 `scripts/lab/social.ts` 的定义一致）：
- 一条假设包含几项配对差时，每项都 ≥ 70% 才算“支持”，每项都 ≤ 50% 算“不支持”，其余算“部分支持”。
- H2a 包含 4 项：
  - 两种渠道条件下的 t50；
  - 听到但不信的人数；
  - 查证的人数。
  后两项把有无推送的分支合在一起比。
- “差距小”类假设按中位差判定：
  - H1d：A−C 的中位差在 [0, 2) 内，且正向的配对不少于反向的；
  - H4c：C−A 的中位差绝对值 < 1；
  - H5c：B−A 的中位差在 [0, 2) 内，且正向的配对不少于反向的；
  - H6c：(A−D)/A 的中位数 < 0.15。
- S5 的信任在 E2 开始那一刻测，只反映 E1 留下的影响。
- t50 未达到按 7 天计。

## 3. 校准问题与假设

### C1 参数敏感性：v1 的结论是不是参数的产物？

做法：
- 14 个手设旋钮（注意基线、推送显著度、提起消息基线、转述忠实度、焦虑补全、可信度斜率、相信阈值、避损权重、惯性、抽样温度、信任幅度等），每个在合理范围的低端、高端各跑一遍；
- 再在全部旋钮的范围内随机抽 200 组参数（拉丁超立方）；
- 场景：经典 30 人小镇的 A–D + “精确标题”分支，以及实验标准镇。

假设：
- HC1a：“加推送比只发网站更快让半数人相信”在 ≥ 95% 的参数组合下成立。
- HC1b：“标题写精确时段比只写‘下午’的过度调整少”在 ≥ 95% 的参数组合下成立。
- HC1c：“渠道对措手不及人数影响小”依赖口耳相传的强度：提起消息的基线调低时，渠道之间的差异会明显变大。
- HC1d：对结果影响最大的旋钮是提起消息基线、注意基线、避损权重（猜测，用来检验直觉）。

### C2 Jev 对规则（经典小镇，seed 42–51，A–D + 精确标题）

- HC2a：Jev 驱动的过度调整在多数分支、多数 seed 下少于规则（3 个 seed 时已如此）。
- HC2b：渠道对照的方向（加推送更快）在 Jev 下同样成立。
- HC2c：逐个决策比较（同一个人、同一刻、同一组选项）时，Jev 选“照常”的概率高于规则。

### C3 中英模板（从 C2 的真实决策请求里抽约 60 条）

比较四种问法：
- 现用：英文指令 + 中文内容；
- 全中文；
- 全英文（内容由 DeepSeek 翻译）；
- 现用问法再问一遍（看 Jev 自身的波动）。

- HC3：三种问法之间的首选一致率 ≥ 80%，且语言造成的差异小于“规则 vs Jev”的差异。

### C4 信任幅度（用 Jev 做“问卷面板”）

做法：
- 让 Jev 扮演经典小镇的 30 位居民，分别设想上一次停电时的 6 种经历：
  - 对照（没有特别经历）；
  - 没收到通知就被打乱；
  - 看了通知没弄清还是被打乱；
  - 通知准确、提前安排好；
  - 标题含糊、白挪一下午；
  - 官方及时澄清。
- 再设想 3 种朋友转述的经历：说成停一整天、说得分毫不差、说错了地方。
- 对每种经历问 4 个问题：对下一次官方通知信几分、会不会照通知改安排、会不会先查证、担不担心。

假设：
- HC4a：“没收到通知就被打乱”让信任下降的幅度（折算到 0–1）大于 social_v1 设的 0.12。
- HC4b：负面经历对信任的影响大于正面经历（负性偏差）。
- HC4c：被坑过的人下次更想先查证；会不会因此更早做准备，方向不确定，由面板回答。

校准结果若改动默认参数，升 `PARAMS_VERSION` / `SOCIAL_RULES_VERSION`，并在 v2 方案里记为新的决定。

## 4. 社会实验与假设

所有实验都在实验标准镇上做，每次只改一个（或两个交叉的）因素。

### S1 渠道 × 标题：更快的渠道会不会把模糊传得更广？（2×2）

分支：

| 分支 | 订推送比例 | 标题 |
| --- | --- | --- |
| A | 10% | 只写“下午” |
| B | 10% | 写 14:00–16:00 |
| C | 70% | 只写“下午” |
| D | 70% | 写 14:00–16:00 |

假设：
- H1a：推送多的镇信得更快（t50：C < A，D < B）。
- H1b：精确标题减少过度调整（B < A，D < C）。
- H1c（核心，交互）：标题模糊时，推送越多、过度调整越多（C > A）；标题精确时推送不增加过度调整。也就是说，差中差 (C−A) − (D−B) > 0。
  直觉：推送只推标题，推得越广，只知道“下午”的人越多。
- H1d：推送多的镇措手不及的人略少，但差距小于 2 人，因为口耳相传会补位。

### S2 信任文化：低信任的镇里，官方渠道还灵吗？（2×2）

分支：

| 分支 | 对官方的信任 | 发布渠道 |
| --- | --- | --- |
| A | 0.8 | 网站 + 公告栏 |
| B | 0.8 | 网站 + 推送 + 公告栏 |
| C | 0.3 | 网站 + 公告栏 |
| D | 0.3 | 网站 + 推送 + 公告栏 |

假设：
- H2a：低信任的镇信得更慢，听到但不信、上网查证的人更多。
- H2b：低信任的镇更依赖口耳相传，所以信过“全天”的人更多。
- H2c（交互）：推送带来的提速在低信任的镇更小。
- H2d：低信任的镇措手不及的人更多。

### S3 焦虑与谣言：谣言是噪声还是保险？（剂量：焦虑 0.25 / 0.45 / 0.65）

- H3a：信过“全天”的人数随焦虑单调上升；焦虑 0.25 时接近 0。
- H3b：过度调整随焦虑上升。
- H3c：措手不及随焦虑下降，即谣言起到“保险”作用。这条预期最弱。

### S4 跨区关系：关系网越连通，外溢越大？（剂量：跨区关系 0.05 / 0.3 / 0.6）

- H4a：跨区关系越多，停电时已知情的总人数越多（南区知道得更多）。
- H4b：停电区外改了安排的人数随跨区关系上升（外溢）。
- H4c：停电区内措手不及的人数基本不受影响。

### S5 失信的代价：沉默一次，下次还信吗？（两轮，同一个北区）

剧本：在 E1 之外加 E2，北区周六（D06）14:00–16:00 再停一次；D05 08:05 发精确标题的通知。三个分支只改 E1：

| 分支 | E1 的通知 |
| --- | --- |
| A | 精确标题 |
| B | 不发通知 |
| C | 标题只写“下午”（默认） |

假设：
- H5a：E1 之后对官方的信任：B < C < A。
- H5b：E2 的相信速度 B 慢于 A，查证的人 B 多于 A。
- H5c：E2 的措手不及 B ≥ A，但差距小，因为口耳相传会补位。
- H5d（两种机制相互竞争，方向不预设）：被坑过的人更不信通知，但也可能更早做准备。E2 改了安排的人数 B 比 A 多还是少，由实验回答。

### S6 澄清时机：来得晚的澄清还有用吗？（标题只写“下午”）

分支：

| 分支 | 澄清 |
| --- | --- |
| A | 不澄清 |
| B | 发布当天中午 D03 12:00 |
| C | 发布当晚 D03 20:00 |
| D | 停电当天上午 D04 11:00 |

假设：
- H6a：任何澄清都减少过度调整，而且越早越好：B < C < D < A。
- H6b：澄清增加停电时知道精确时段的人数。
- H6c：停电当天上午的澄清对过度调整几乎无效，因为多数人已经改了安排，而且未必改回来。

## 5. 结果

以下都是跑完后追加的。原始汇总在 [results/](results/)，脚本在 `scripts/lab/`。花费：本轮真实模型调用约 $1.24。

### 5.1 C1 参数敏感性：一半的 v1 结论是参数和运气的产物

规模：
- 经典小镇 5 个分支、实验镇 4 个分支；
- 参数：一次改一个旋钮（14 个旋钮 × 低/高 × 20 seed），加 200 组随机参数（× 8 seed）；
- 共约 2.2 万次运行，8 线程 3 分钟跑完。

结论在各参数组合下成立的比例（“成立”指 seed 配对差的中位数方向正确）：

| 结论 | 经典镇 默认参数 20 seed | 经典镇 200 组参数 | 实验镇 默认参数 | 实验镇 200 组参数 |
| --- | --- | --- | --- | --- |
| 加推送 / 多渠道让人信得更快 | 100% | 100% | 100% | 100% |
| 加推送 / 多渠道减少措手不及 | 75%（反向 15%） | 84%（反向 5%） | 80%（反向 5%） | 89%（反向 2%） |
| 精确标题减少过度调整 | 45%（反向 45%） | 55%（反向 43%） | 70%（反向 30%） | 75%（反向 25%） |
| 16:00 澄清减少过度调整 | 55%（反向 45%） | 36%（反向 64%） | 40%（反向 60%） | 49%（反向 52%） |
| 精确标题减少措手不及 | 30%（反向 30%） | 22%（反向 36%） | 30%（反向 45%） | 14%（反向 20%） |

哪些旋钮最要紧（200 组参数下旋钮取值与结果的秩相关，实验镇 / 经典镇）：
- 信得多快：相信阈值（+0.86 / +0.55）、口耳相传对关系信任的斜率（−0.32 / −0.48）、提起消息的基线（经典镇 −0.45）。
- 措手不及：口耳相传的斜率（−0.59 / −0.51）、相信阈值（+0.57 / +0.50）。
- 过度调整：避损权重（+0.66 / +0.43）、口耳相传的斜率（+0.51 / +0.52）。
- 信过“全天”：焦虑补全的强度（+0.32 / +0.39）。
- 渠道带来的差异（提速、少措手不及）：主要取决于提起消息的基线（−0.45 至 −0.63）。口耳相传越强，渠道之间的差异越小。
- 标题与澄清带来的差异：没有任何旋钮的秩相关超过 0.2。它们主要是随机性，不是参数。

对照假设：
- HC1a **支持**：100%。
- HC1b **不支持**：55% / 75%，远低于 95%。v0 单 seed 时的说法“最大的代价来自标题的模糊”站不住。
- HC1c **支持**：提起消息的基线从低到高，“加推送少措手不及”的中位差在经典镇从 3 人降到 0 人，在实验镇从 4 人降到 1 人。
- HC1d **部分支持**：提起消息的基线、避损权重猜对了；注意基线不在前列；排第一的其实是可信度那一组（相信阈值、口耳相传的斜率），这一组没猜到。

### 5.2 C2 Jev 对规则：方向一致，路径不同

规模：经典小镇 5 个分支 × seed 42–51；Jev 共 2523 次调用（缓存命中 917），1 次回退，花费 $0.067。

结果层面（10 个 seed 的中位数，Jev | 规则）：

| 分支 | 半数相信用时 | 措手不及 | 过度调整（分钟） | 上网查证 |
| --- | --- | --- | --- | --- |
| A 仅网站 | 23.3 h \| 23.0 h | 3 \| 3.5 | 369 \| 522 | 16.5 \| 13.5 |
| B + 公告栏 | 7.6 h \| 4.6 h | 1 \| 2 | 482 \| 603 | 17 \| 13.5 |
| C + 推送 | 10.0 h \| 4.8 h | 1 \| 1.5 | 383 \| 630 | 15.5 \| 12.5 |
| D + 推送 + 澄清 | 7.9 h \| 4.8 h | 1.5 \| 1 | 321 \| 417 | 15.5 \| 12.5 |
| E + 推送，精确标题 | 4.9 h \| 3.8 h | 1 \| 2 | 375 \| 650 | 15 \| 11 |

- 结论方向：“加推送更快”两种心智都是 10/10；“精确标题少过度调整”两种心智都只有 4/10，与 C1 互相印证。
- 逐决策（2168 个相同请求）：
  - 首选一致 62%，选择分布的平均差异（TV）0.29。
  - Jev 更爱先查证（选择概率 0.87 对 0.71）、更爱就地变通（0.28 对 0.11），很少整段搬走（0.14 对 0.36）。
  - Jev 的居民更不担心（0.33 对 0.49，但两者相关 0.69），更想查证（0.71 对 0.52，相关只有 0.14），更少主动发消息（0.59 对 0.74）。

对照假设：
- HC2a **部分支持**：5 个分支的中位数都是 Jev 更低，但逐 seed 只有 4–8/10。
- HC2b **支持**。
- HC2c **不支持**：Jev 选“照常”的概率反而略低（0.22 对 0.27）。过度调整少，是因为 Jev 的居民选了代价小的就地变通，而不是更爱照常。

**C2b 规则心智向 Jev 校准**：在留出的 seed 47–51（1288 个请求）上：
- 首选一致率从 62% 升到 82%；
- KL 从 0.42 降到 0.17；
- 发消息概率的交叉熵从 0.041 降到 0.011。

结果层面只改善了一点：5 个分支 × 6 个指标，与 Jev 中位数的平均相对差距从 0.29 降到 0.25。半数相信用时仍有差距，但两种心智下相信、转告的总人数几乎一样（例如 C 分支都是 28 / 29 人），差距主要来自 30 人小镇里“第 15 个人何时相信”的时机噪声。

### 5.3 C3 中英模板：语言有影响，但远小于心智差异

60 个真实请求（40 个反应、20 个通知）。四种问法的比较：

| 比较 | 选择首选一致 | 选择分布差异（TV） | 契合度首选一致 |
| --- | --- | --- | --- |
| 现用问法再问一遍（Jev 自身波动） | 97.5% | 0.017 | 97.5% |
| 换指令语言（中文指令） | 95% | 0.043 | 87.5% |
| 换内容语言（DeepSeek 译成英文） | 85% | 0.079 | 75% |
| 全中文 vs 全英文 | 87.5% | 0.091 | 70% |
| 参照：规则 vs Jev（现用问法） | 72.5% | 0.282 | 20% |

- HC3 **支持**（按选择层面）：三种问法之间的首选一致率都 ≥ 85%，语言造成的差异只有心智差异的 1/3 到 1/7。
- 但契合度这一层（Jev 直接给的“最像他会做的”），换内容语言会改变四分之一的首选。
- 决定保留现有问法（D44）。没有真值时，无法判断哪种语言更“准”。

### 5.4 C4 信任面板：幅度大多设小了，而且信任和谨慎是两回事

30 位居民 × 10 种经历，每格问 4 个问题，花费 $0.01。
- 同一问题问两遍，平均只差 0.007。
- 面板里的基线信任与居民设定的信任特质相关 0.85。

各经历相对对照的变化（逐人配对，括号是 95% 区间，0–1 标尺）：

| 经历 | 对官方 / 朋友的信任 | 照下次通知改安排 | 先查证 | 担心 | social_v1 设的幅度 |
| --- | --- | --- | --- | --- | --- |
| 没收到通知就被打乱 | −0.11（−0.13, −0.09） | **+0.05** | +0.03 | **+0.13** | −0.12 |
| 看了通知没弄清，还是被打乱 | −0.10（−0.12, −0.09） | −0.05 | +0.01 | +0.10 | −0.04 |
| 通知准确，提前安排好 | **+0.14**（+0.12, +0.16） | +0.13 | −0.03 | −0.06 | +0.04 |

- **S4 / S4b 跨区关系**：
  - 无论三渠道发布还是只发网站，跨区关系从 0.05 调到 0.6，知情人数、外溢、措手不及都不变，两种心智一致。

- **S5 / S5b 失信的代价**：

- **S6 澄清时机**：
  - 澄清一定增加知道精确时段的人（90–100%）。
  - 对过度调整：规则心智下几乎无效。
  - Jev 下，中午澄清让中位数少了三分之一（1032 → 681 分钟），而且按澄清的早晚排序；但每一项只有 6/10，证据偏弱。
- **S7 连续失信（探索性）**：
  - 两轮都不通知，第三轮开始时对官方的信任低约 0.12（规则 60/60，Jev 10/10）。
  - 第三轮仍然没有人“不信”，措手不及也不增加（Jev 下反而更少）。
  - 但**照通知改安排的人明显少了**：Jev 中位少 3.5 人，9/10 个 seed 如此；规则中位少 1 人，62%。
  - 对比只沉默一次的 S5（Jev 中位少 1 人，5/10），呈现剂量效应。
  - 模型里没有“不再相信官方”的临界点，但失信的代价会随次数累积，慢慢渗到行为上。

## 6. 洞察

以下都是“这个模型下”的洞察。每一条都注明它在哪些模型下成立。

### 6.1 渠道决定谁知道、多快知道，却几乎决定不了知道得准不准、改得对不对

- 推送或公告栏让半数人相信的时间缩短数倍到数十倍：
  - 经典镇从约 23 小时缩到约 4 小时；
  - 实验镇从约 3.7 小时缩到几分钟。
  这在全部 200 组参数、两种心智、三个模型版本下都成立（100%），是全部实验里最稳的结论。
- 标题写精确、事后澄清，对“白挪安排”的作用时有时无：
  - 在参数空间里只有 36–75% 成立；
  - 秩相关显示它几乎不受任何参数控制，主要是随机性。
- 为什么：精确时段在口耳相传里会衰减（每次口头转述约有两成把“14:00–16:00”说成“下午”之类的大概），而已经挪好的安排有惯性。
- 真正决定过度调整的是人群本身：
  - 避损权重和焦虑（S3：焦虑越高，过度调整越多）；
  - 对口耳相传的信任。
- 换句话说：**过度反应更像是人群的性格，而不是通知的措辞**。
- 这推翻了我在 v0（单 seed）时的说法“最大的代价来自标题的模糊”。

### 6.2 口耳相传是小镇看不见的基础设施

- 敏感性分析里，调节“渠道有多重要”的头号旋钮是提起消息的概率。口耳相传越强，渠道之间的差异越小。
- 跨区关系从 0.05 调到 0.6，什么都没变（S4、S4b，两种心智一致）。在 60 人的镇上，同区的家人、同事、邻居已经把消息传到了，桥接关系没有用武之地。
- 所以这类小镇的韧性来自邻里本身，而不是关系网的结构。
- 反过来推：真正会让渠道和关系结构变得要紧的，是更大的规模、或者更原子化的社区（邻里之间少说话）。这是下一步该扩到 120 人的理由。

### 6.3 失信的代价先记在“信任”这本账上，不会马上体现在行为上

- 第一轮不发通知，对官方的信任在每一次重复里都下降。
- 但第二轮、甚至第三轮的措手不及并不增加，Jev 下反而更少（S5、S5b、S7）。
- 代价会随次数累积，而且先表现为“照通知做的人变少”：
  - 沉默一次，第二轮改安排的人几乎不变（Jev 中位 −1，5/10）；
  - 沉默两次，第三轮少了 3.5 人（Jev 9/10）。
- 两个机制吸收了代价：
  1. 邻里转告补位；
  2. 被坑过的人变得更谨慎。信任面板里，他们的信任降了 0.11，照下一次通知改安排的概率却高了 5 个百分点，担心也多了 0.13，典型的“一朝被蛇咬”。
- 模型里官方通知的可信度有下限（0.5 + 0.45 × 信任）：信任降到 0.3 时可信度仍是 0.64，高于相信阈值 0.55。所以没有“不再相信官方”的临界点；S7 连续两次沉默后，第三轮“不信”的仍然是 0 人（两种心智一致）。
- **这是模型最强、也最该用现实数据检验的假设**：
  - 现实里，长期失信可能有临界点，也就是“狼来了”的反面，“狼没喊就来了”；
  - 这个模型表达不了这种临界点。

### 6.4 低信任让社会变慢，但不一定变乱；而查证本身也依赖信任

- 低信任的镇信得更慢：无推送时 Jev 慢约 3 小时，规则慢约 1 小时；但“不信”几乎为 0，措手不及只多 1 人左右。
- 两种心智在“查证”上给出相反的方向：
  - 规则心智按直觉写成“越不信越要查”；
  - Jev 认为“越不信越不去官网查”。
  - 后者更耐人寻味：查证的渠道本身就是官方的，不信官方的人不会把它当作可靠的来源。
  - 信任面板里有独立的证据：对照情境下，“会不会先查证”与信任正相关（r = 0.29–0.38），与细致程度也正相关（0.51–0.57）。
  - 也就是说，规则心智里“不信官方”这一项的符号写反了（留作下一步，见 6.7）。
  - 如果这是真的，“让大家自己去官网核实”在低信任社区恰恰最不管用。
- 推送在低信任的镇里提速反而更多（Jev），因为那里没有推送时格外慢。与我的假设 H2c 相反：**越不被信任的机构，越需要主动推送**。

### 6.5 焦虑制造谣言，谣言制造折腾，但谣言不是保险

- “停一整天”的谣言有门槛：焦虑从 0.25 到 0.45 几乎不变，到 0.65 才冒出来。这来自“焦虑补全”机制：个人焦虑超过 0.45 才会把不知道的时段补成“全天”。
- 谣言与过度调整一起上升，却没有减少措手不及：在一个几乎人人知情的镇上，本来就没有什么需要它来“保”。

### 6.6 方法论：结论要落在“两种心智 × 参数空间”的交集上

- 我预注册的 20 条假设，三种模型下都成立的只有 5 条。
- 我的直觉系统性地高估了“消息怎么写”的作用，低估了“社会怎么吸收”的作用。
- 同一个问题，结论可能在三个层面上翻转：
  - 单 seed → 多 seed：v0 的“标题模糊代价最大”被推翻；
  - 校准前 → 校准后：S1 的交互作用从 67% 变成 52%；
  - 规则 → Jev：S2 的查证方向、S1 的交互方向都相反。
- 所以在这个平台上，一条结论要同时满足四个条件才可信：
  - 多个 seed、多座镇；
  - 对参数不敏感；
  - 规则与 Jev 两种心智都成立；
  - 最好还有面板之类的独立证据。
  符合的结论（6.1 的渠道提速、6.3 的“信任掉了，措手不及没变”）可以放心讲；其余只能当作“这个模型的性质”。
- 实验还反过来改进了模型。三处缺口都是看了实验数据才发现的：
  - 挪动不能“缩小”；
  - 为谣言关门造成的不便无处归因；
  - 信任只有一条通道，表达不了“被坑之后更谨慎”。

### 6.7 局限与下一步

局限：
- Jev 模式只有 10 个 seed；判定为“部分支持”的不少是统计力不够。
- 全部实验都在同一种“河分南北”的骨架上，规模 30–60 人，只有停电一类事件。
- 校准的“真值”是 Jev，不是现实。
- 面板的情境是英文、人设是中文；C3 显示语言会改变约 15% 的首选。

下一步建议：
1. 找现实数据检验两条强假设：
   - 官方通知的可信度下限（有没有临界点）；
   - 口耳相传的强度。
   能拿到的数据，比如一次真实停电通知后的社区问卷，或者物业群的转发记录。
2. 扩到 120 人，并做一个“原子化”的社区（邻里少交谈），检验 6.2 的推论：规模与原子化会不会让渠道和关系结构重新变得要紧。
3. 把规则心智里查证与信任的关系改成正向（面板和 S2 两处证据都指向这一点），再用 Jev 复核 S2。
