## 1. 为什么选这三个

| 案例 | 经典说法 | 这里能不能检验 |
| --- | --- | --- |
| 狼来了 | 虚惊多了，下次警报没人听（寓言；Breznitz 1984 的 cry-wolf 效应）。实证研究并不一致：飓风撤离的研究发现虚惊后照样撤离（Dow & Cutter 1998），龙卷风研究却发现虚警率高的地方伤亡更多（Simmons & Sutter 2009） | 检验。虚惊的心理幅度由 Jev 信任面板量出来，行为后果是涌现的 |
| 知沟 | 大众媒介的信息越多，信息优势群体吸收得越快，差距反而扩大（Tichenor, Donohue & Olien 1970）；话题切身、人际讨论多时，差距会因天花板效应缩小 | 检验。谁订推送、谁晨练路过公告栏、谁和谁住在一起是设定；差距怎样变化是涌现的 |
| 传话游戏 | 连续转述中细节被磨平、少数被加重、向预期同化（Bartlett 1932；Allport & Postman 1947）；谣言强度 ≈ 重要性 × 模糊度 | 一半是演示：每传一手丢多少细节，是写进模型的参数。另一半是检验：谁去传、走样的版本最后占多少人、官方原文能不能把走样拉回来，都是涌现的 |

**演示与检验的区别**要在文章里讲清楚：
- 结果只是把参数读回来的，叫“演示”；
- 结果取决于很多规则的相互作用、事先算不出来的，才叫“检验”。

## 2. 方法约定（沿用上一份实验记录）

**重复**：
- 规则模式：3 座实验镇（生成种子 42 / 7 / 99）× 每座 20 个运行 seed，共 60 次；
- Jev 模式：实验镇 42 × 10 个 seed。

**判定**：
- 同一座镇、同一个 seed 的分支两两配对；
- 预测方向在 ≥ 70% 的配对里成立，记“支持”；≤ 50%，记“不支持”；其余记“部分支持”；
- 一条假设含几项时，每项都 ≥ 70% 才算“支持”，每项都 ≤ 50% 才算“不支持”；
- “差距小”类按中位差判定，细则写在各条假设里；
- t50 未达到按 7 天计。

**两种心智都要报告**：
- 只在两种心智下都成立的，才写进文章的结论；
- 其余标明“只在规则 / 只在 Jev 下成立”。

**实验标准镇（60 人）**：
- 河分南北，老人、青年各 25%，订推送 30%，常看网站 25%，公告栏 2 块，对官方的平均信任约 0.6；
- 案例 K 改了人口结构，见第 4 节。

## 3. 案例 W：狼来了

### 3.1 设计

同一个北区，隔天停电一次，共三轮，都是 14:00–16:00：

| 轮次 | 停电日 | 通知 |
| --- | --- | --- |
| E1 | 周三 D03 | 前一天 08:05，网站 + 推送 + 公告栏，标题写精确时段 |
| E2 | 周五 D05 | 同上 |
| E3 | 周日 D07 | 同上。这一轮是**检验轮**，所有分支都真的停电 |

五个分支只改 E1、E2：

| 分支 | E1 | E2 | 含义 |
| --- | --- | --- | --- |
| A 没有前情 | 不存在 | 不存在 | 这个镇从没停过电 |
| B 两次准确 | 真停电，准确通知 | 真停电，准确通知 | 机构说到做到 |
| C 一次虚惊 | 不存在 | 虚惊：发了通知但没停 | |
| D 两次虚惊 | 虚惊 | 虚惊 | 狼来了 |
| E 两次漏报 | 真停电，不发通知 | 真停电，不发通知 | 对照：漏报 vs 虚报 |

### 3.2 需要补的机制：虚惊

- **事件**：
  - 一轮停电可以标成“虚惊”：照常发通知、发工单，但不断电；
  - 到通知所说的恢复供电时刻，真相才可见：北区的电一直没断。
- **后果结算**：
  - 为这轮挪动或改掉的安排，全部计为过度调整；
  - 没有人会措手不及。
- **信任裁决**（每个见证者只归入一类，与上一份记录的 social_v2 一致）：
  - 信了通知、改了安排 → “虚惊，白挪了安排”；
  - 信了通知、没改安排 → “虚惊，但没耽误什么”；
  - 没听说 → 不变；
  - 转述者如实传了官方的话 → 对转述者的信任不变。
- **幅度来源**：
  - 跑实验之前，先用 Jev 信任面板（30 位居民）补问三种经历：
    - 虚惊，白挪安排；
    - 虚惊，没耽误；
    - 一个月内两次虚惊；
  - 对信任、照做、查证、担心的平均变化，直接作为规则参数；
  - “两次虚惊”那一格只用来检查“按次数叠加”是否合理，不单独设参数。

### 3.3 假设

| 编号 | 假设 | 判定 |
| --- | --- | --- |
| HW1 | 虚惊伤信任：E3 开始时对官方的信任 D < C < A | 两项：A−C、C−D 都 > 0 |
| HW2 | 狼来了（经典）：两次虚惊后，E3 照通知改安排的人更少 | A−D > 0 |
| HW3 | 一次不够：一次虚惊几乎不改变 E3 照做的人数 | C−A 的中位差绝对值 < 1 人 |
| HW4 | 社会吸收：两次虚惊后，E3 措手不及的人不明显增多 | D−A 的中位差 < 1 人，且正向的配对不超过 50% |
| HW5a | 虚报比漏报更伤信任 | E3 开始时的信任 E−D > 0 |
| HW5b | 虚报比漏报更伤照做 | E3 改安排的人 E−D > 0 |

报告但不预设方向：E3 的查证人数、半数相信用时、“听到但不信”的人数。

我事先的直觉：
- HW1、HW3、HW4 会成立；
- HW2 会成立，但幅度不大；
- HW5 最没把握：
  - 虚惊碰到的是所有信了通知的人，漏报只碰到被打乱的那十来个人，所以我猜虚报更伤信任；
  - 被坑过的人会更谨慎，所以我也猜虚报更伤照做。

## 4. 案例 K：知沟

### 4.1 设计

镇的人口结构改成老人 40%、青年 30%，其余同标准镇，以保证两组都有 15 人以上。停电剧本同标准镇：北区 D04 14:00–16:00，D03 08:05 发通知，标题只写“下午”。

四个分支只改通知渠道：

| 分支 | 渠道 |
| --- | --- |
| A | 只发网站 |
| B | 网站 + 推送 |
| C | 网站 + 公告栏 |
| D | 网站 + 推送 + 公告栏 |

分组：青年 18–29 岁，老人 60 岁及以上，中年作参照。

每组的指标：
- 组内半数相信用时（从第一条消息算起）；
- 停电那一刻知情的比例、知道精确时段的比例；
- 住在北区的组员里措手不及的比例。

差距的定义（数值越大，老人越吃亏）：
- 速度差 = 老人组的半数相信用时 − 青年组的；
- 知情差、精确差 = 青年组比例 − 老人组比例；
- 措手不及差 = 老人组比例 − 青年组比例。

### 4.2 假设

| 编号 | 假设 | 判定 |
| --- | --- | --- |
| HK1 | 知沟（速度）：推送拉大速度差 | 速度差 B−A > 0 |
| HK2 | 天花板（终局）：推送不拉大停电时的知情差 | 知情差 B−A 的中位差绝对值 < 5 个百分点 |
| HK3 | 公告栏缩小速度差 | 速度差 A−C > 0 |
| HK4 | 推送带来的是“早知道”，不是“知道得准” | 精确差 B−A 的中位差 < 5 个百分点 |
| HK5 | 只发网站时老人更容易措手不及；公告栏比推送更能缩小这个差距 | 两项：A 的措手不及差 > 0；措手不及差 B−C > 0 |

我事先的直觉：
- HK1、HK3 会成立；
- HK2 成立：家人会告诉老人；
- HK4 成立：推送只带标题“下午”，精确时段在网站正文里，而常看网站的人里老人偏多，精确差甚至可能反过来；
- HK5 的措手不及人数很少，可能没有统计力。

## 5. 案例 R：传话游戏

### 5.1 设计

标准镇，北区 D04 14:00–16:00 停电。四个分支只改“模糊度”：

| 分支 | 通知 |
| --- | --- |
| A | 标题写精确时段（三渠道，D03 08:05） |
| B | 标题只写“下午”（默认） |
| C | 标题不写时间（正文仍有精确时段） |
| D | 不发通知，只有维护站的工单：最初只有技术员知道，其余全靠口耳相传 |

指标（都截止到停电开始）：
- 谣言强度：
  - 人传人的转述次数（当面 + 私信）；
  - 主张版本数；
  - “信过走样版本”的人数：信的时段不是精确时段（只知道大概、不知道、“全天”），或者丢了地点。
- 重要性：按说话人住在北区（要停电）还是南区（不停电），分别算人均转述次数。
- 磨平曲线：给每个人记一个“第几手”：
  - 最先从官方渠道（网站、推送、公告栏、工单）得知的算第 0 手；
  - 最先从某人那里得知的，算那人的手数 + 1。
  - 每次转述的手数 = 说话人的手数 + 1。
  - 看各手数的转述里，带精确时段的比例。
- 同化：信过“全天”的人数。

### 5.2 假设

| 编号 | 类型 | 假设 | 判定 |
| --- | --- | --- | --- |
| HR1 | 检验 | 模糊度越高，信过走样版本的人越多 | 三项：B−A、C−B、D−C 都 > 0 |
| HR2 | 检验 | 重要性：北区（要停电）的人均转述多于南区 | 在 B、D 两个分支里，北−南 都 > 0 |
| HR3 | 检验 | 重要性 × 模糊度：模糊度对转述的推动在北区更大 | 差中差 [北(D)−北(A)] − [南(D)−南(A)] > 0 |
| HR4 | 演示 | 磨平：没有官方原文时，精确时段随手数衰减 | D 分支里，第 1 手带精确时段的比例 > 第 3 手 |
| HR5 | 检验 | 官方原文把走样拉回来：有通知时，衰减比没通知时平缓 | 差中差 [第1手−第3手](D) − [第1手−第3手](B) > 0 |
| HR6 | 检验 | 同化：“全天”只在缺时间信息时出现 | A、B 的中位数 ≤ 0.5；D−B > 0 |

需要事先说明：
- 转述与变形由规则决定，Jev 只影响“主动发消息”和“改安排”，所以这个案例两种心智的差别主要来自私信。
- HR4 的衰减速度就是模型参数（精确时段原样转述的概率约 0.76），这一条只是演示。

我事先的直觉：
- HR1、HR2、HR6 会成立；
- HR3 会成立：焦虑补全“全天”只在说话人自己不知道时段时发生，而北区的人更关心；
- HR5 是我最想看的：真实社区里的传话不是一条链而是一张网，只要官方原文还在，走样的版本会不断被纠正，所以我猜会成立。

## 6. 结果

以下是跑完后追加的。汇总数据在 [results/cases.json](results/cases.json)，脚本是 `scripts/lab/cases.ts`。花费：Jev 部分 $0.49，虚惊面板 $0.003。

### 6.0 虚惊的幅度（跑实验之前量出并提交）

按第 3.2 节的约定，先用 Jev 信任面板量出虚惊的心理幅度（30 位居民，逐人与“没有特别经历”配对）：

| 经历 | 对官方的信任 | 照下次通知做 | 先查证 | 担心 |
| --- | --- | --- | --- | --- |
| 虚惊，白挪了安排 | −0.13（−0.15, −0.11） | −8 个百分点 | +0.02 | +0.02 |
| 虚惊，没耽误什么 | −0.09（−0.10, −0.07） | **−15 个百分点** | 0.00 | −0.05 |
| 两周内两次虚惊 | −0.24（−0.27, −0.22） | −25 个百分点 | +0.03 | +0.02 |

对照：上一份记录里“没收到通知就被打乱”的人，照做反而 +5 个百分点。在 Jev 眼里，漏报让人更谨慎，虚报让人松懈。

落到模型上有三处，都在跑任何一个案例之前定下并提交：
- 信任幅度取前两行（−0.13 / −0.09）；
- 两次虚惊 ≈ 两次单独的效应之和，所以经历记忆按次数叠加；
- “照下次通知做”的变化写成规则心智里“照常”的效用加减。
  - 预注册只说了它会成为参数。为了让“虚报 vs 漏报”的比较公平，所有经历类型都用同一个面板的照做变化，而不只是虚惊。
  - 这一项只作用于规则心智：Jev 从观察里的过往经历自己判断。

### 6.1 狼来了：寓言成立，但比寓言温和，而且虚报比漏报更伤

- **信任（HW1）**：两种心智下都是 100% 的重复里 D < C < A。两次虚惊后信任从 0.62 降到 0.49。
- **狼来了（HW2）**：两次虚惊后，第三次真停电时照通知改安排的人更少。规则心智少 5 人（约四分之一，93%），Jev 少 1.5 人（80%）。**两种心智都支持**。
- **社会吸收（HW4）**：措手不及的人没有明显增多，两种心智都是 0–1 人。照做的人少了，但通知仍然传到了。
- **虚报 vs 漏报（HW5）**：两次虚惊比两次漏报更伤信任（多掉 0.09–0.10，100%），也更伤照做（多少 2–5 人，90–95%）。两种心智都支持。
  - 但两种失败的代价形态不同：两次漏报让 22 人次措手不及；两次虚惊没有人措手不及，却让大家白挪了约 100 小时的安排。
- **一次虚惊（HW3）**：两种心智都否定了“几乎没影响”，但方向相反。
  - 规则心智：一次就少 2 人（73%）；
  - Jev：一次虚惊后照做的人反而多 1 人（70%）。
  - 这一条只能说“一次虚惊的影响不确定”。
- **两次虚惊后**，Jev 的居民去官网查证的也更少了（70% 的重复里减少）。

### 6.2 知沟：推送让差距更大，比我猜的更严重；公告栏把差距反过来

- **速度差（HK1）**：只发网站时，老人甚至比青年先过半（常看网站的人里老人偏多）；加推送后青年约 30–40 分钟过半、老人要约 22 小时。两种心智都是 97–100%。
- **天花板效应（HK2）没有出现**：停电那一刻，推送让青年比老人多知情 7（Jev）到 17（规则）个百分点，80–88% 的重复如此。我原以为家人会把消息带给老人、差距会缩小，并没有。
- **精确差（HK4）也被推送拉大了**：多 17–20 个百分点。推送带来的不只是“早知道”。
- **公告栏（HK3）**：公告栏把速度差反过来，老人约 2.2 小时过半、青年约 10 小时，两种心智都是 92–100%。三渠道一起时两边都快，差距最小。
- **措手不及（HK5）**：人数太少（中位数 0），没有统计力，判为不支持。

### 6.3 传话游戏：有官方原文在，走样有上限；没有它，第三手时精确时段几乎消失

- **磨平（HR4，演示）**：不发通知、只靠工单与口耳相传时，带精确时段的转述从第 1 手的 75–85% 掉到第 3 手的 0–17%。
- **官方原文把走样拉回来（HR5）**：有通知时同样的衰减平缓得多（第 1 手 38–42%，第 3 手 24–32%）。两种心智都是 93–100%。
  - 真实社区里的传话不是一条链，而是一张网，官方原文不断把走样的版本拉回来。
- **重要性（HR2）**：要停电的北区，人均转述是南区的约 2 倍，两种心智都是 97–100%。
- **重要性 × 模糊度（HR3）**：规则 57%，Jev 反向（40% / 60%）。Allport–Postman 的“乘法”没有得到支持：重要性和模糊度各自起作用，但没有相乘。
- **模糊度（HR1）**：部分支持。
  - 标题只写“下午”比写精确时段多 3–5 人信过走样版本（60–78%）；
  - 不写时间和只写“下午”几乎没差别；
  - 不发通知时“信过走样”的人数反而更少，只是因为听说的人少了一半（约 31 人 vs 59 人）。按预注册，这里比的是人数而不是比例，所以如实记为不成立。
- **同化（HR6）**：“停一整天”只在缺时间信息时出现。规则心智支持，Jev 部分支持（D−B 只在 50% 的重复里为正）。

### 6.4 汇总

预注册的 16 条“检验”（不含演示与报告）：

| | 条数 | 编号 |
| --- | --- | --- |
| 两种心智都支持 | 9 | HW1、HW2、HW4、HW5a、HW5b、HK1、HK3、HR2、HR5 |
| 两种心智都不支持 | 4 | HW3（方向相反）、HK2、HK4、HK5 |
| 两边不一致或部分支持 | 3 | HR1、HR3、HR6 |

我事先的直觉错在三处：
- 以为一次虚惊没事；
- 以为家人会把知沟填平；
- 以为 Allport–Postman 的乘法会成立。

## 7. 讨论

**狼来了在这座小镇里是真的，但它伤的是“信”和“做”，不是“知道”。**
- 两次虚惊后，信任降了一截，照通知做的人少了；
- 但因为通知照样传遍全镇，被停电打个措手不及的人并没有增加。
- 这和实证研究里 cry-wolf 效应“比寓言温和”的发现一致。
- 值得注意的是“虚报 vs 漏报”：
  - 漏报伤的是当下：22 人次措手不及；
  - 虚报伤的是以后：信任和照做都掉得更多。
  - 一个只想“别让人措手不及”的机构，可能会宁可多发警报。这个模型提醒：这样做的代价是下一次有人不照做。

**渠道就是不平等的设计。**
- 同样一条通知，放在推送里就先到年轻人手里，贴在公告栏上就先到老人眼里；
- 停电那一刻，谁知道、谁知道得准，也跟着渠道走，家人并没有把差距填平；
- 只有几种渠道一起用，差距才最小。
- 这是 Tichenor 知沟假说的一个干净复现，而且比经典版本更强：差距不止在速度上，也在终局上。

**传话游戏的关键不是“话会传歪”，而是“有没有一份原文”。**
- 没有官方原文时，到第三个人手里精确时段几乎消失；
- 有原文在时，走样被不断纠正，停在一个稳定的水平；
- 这比“把标题写清楚”重要得多，呼应上一份记录的发现：标题措辞的效果不稳。

**模型的局限。**
- 虚惊的心理幅度来自 Jev 面板，不是来自现实；
- 知沟里的年龄差异来自设定：谁订推送、谁晨练，是生成器的规则；
- 传话的衰减速度是参数；
- 三个案例都在同一种“河分南北”的 60 人小镇上。
