# 七个影响案例：一件事落到一个社区里，日子会怎么变？

- 日期：2026-11-19
- 状态：done（2026-11-19 运行）
- 作者：Jim Lin（由 Claude 执行）
- 平台版本：预注册时为 v5 的 M4 内核（提交号见本文件的首次提交）；结果一节写明运行时的提交号
- 边界：结论都是“这个模型下的结论”，不是现实预测。新内核只有规则心智，没有用决策模型复核；参数没有对照现实数据校准过（见 v5 方案 D87）。

## 1. 问题与经典说法

新内核（v5）里的社区会自己过日子。这一组实验问的是：往里放一件常见的事，宏观的数字和具体的人各会怎么变。七件事都取自日常听得到的说法：

| 案例 | 常听到的说法 |
| --- | --- |
| 菜市场关了 | “菜市场一拆，老人买菜难，也没地方碰面了。” |
| 活动中心办食堂 | “社区食堂能让独居老人有个说话的地方；也有人说它抢小饭馆的生意。” |
| 涨价的传言 | “一说要涨价，大家就去抢，结果真的买不到。”（自我实现的预言） |
| 连下一周雨 | “下雨天老人就闷在家里。” |
| 车间裁员 | “厂里一裁人，门口的小馆子先冷清。”（乘数效应） |
| 每户发 500 元 | “发了钱，人们会去消费。” |
| 房租涨三成 | “房租一涨，先省的是吃的。” |

它们大多是“检验”：结果取决于需求、钱、营业时间、库存、谁在哪儿这些规则的相互作用，事先算不出来。只有两条接近“演示”，在第 3 节标了出来。

## 2. 设计

- 社区：老城街坊（和平里）、工厂镇（红星厂）、城中村（塘尾村），都用预设规格。
- 干预：每个案例一条，见 `apps/studio/src/lab/presets.ts`（实验台里的“影响案例”就是它）。
- 对照：同一个社区、同一个种子，基线与干预两条世界线。
- 重复：每个案例 5 个种子（1–5）；天数 12–21 天。指标取干预开始之后的日子（房租一例从第二次收租的第 8 天起）。
- 指标：`packages/society/src/metrics/indicators.ts` 里的键。
- 脚本：`node --import tsx scripts/lab/impact.ts`，只在内存里跑。

## 4. 事先的直觉

写在运行之前。我对这个模型的了解比对现实多，所以这里猜的是“模型会说什么”：

- **菜市场**：M1、M2 会成立，两家小超市每天各只补 320 份菜，接不住全社区。M3 我没把握：买菜时的闲聊只是老人聊天的一小部分，下棋打牌才是大头，可能看不出差别。M4 可能成立，买不到菜的家庭会出去吃。
- **食堂**：C3 会成立。C2 我猜成立但幅度小，九块钱的饭主要抢的是在家吃的那几顿。C1 我猜**不成立或看不出**：在食堂吃饭时能和同桌聊上，但模型里老人本来聊得就多，一整天没聊过天的老人主要是不出门的那几位，他们未必会为了一顿饭出门。C4 多半看不出。
- **传言**：R2 会成立。R1、R3 取决于囤的量够不够把货架买空，我猜 R3 成立、R1 在五个种子里大多成立。
- **下雨**：W1 成立。W2 我猜成立。W3、W4 我猜成立但幅度不大，因为茶馆和活动中心接得住一部分人。
- **裁员**：L3 成立。L1、L2 我猜**不明确**：被裁的人手里还有存款，三周内未必收紧；而且他们白天有空了，反而可能多出去吃。L4 我猜**相反**：模型里的心情只由吃饱、精力、社交、乐趣算出，没有“丢了工作”这件事本身的分量，不上班的人反而更闲、更有乐趣。如果真是这样，这是模型缺的东西，不是发现。
- **发钱**：V3、V1 我猜成立但幅度很小：钱进的是家庭账户，个人钱包没变，只有“手头紧”的那一项会松一点。V2 不明确。
- **房租**：T1 成立。T2、T3 我猜**看不出**，理由同上：房租从家庭账户出，对个人下馆子的影响只通过“手头紧”这一项，而且只有余额很低的家庭才会感到。

如果 L4、V、T 这几条如我所料落空，说明模型里“钱”对行为的传导太弱，这是 v5 之后该补的机制。

## 6. 讨论

**安慰剂的差几乎都是零。** 这是没想到的：给每户发 1 元，此后三周里所有指标与基线分毫不差（只有家庭账户多了那 1 元）。原因是随机数按键计算（v5 方案 D88）：只要一个人面对的候选和效用没变，抽到的还是同一个选择，世界线不会因为“被碰了一下”就混沌地分开。这意味着表里哪怕很小的差，也是干预沿着因果链传过去的，不是噪声；但也意味着五个种子之间的差异来自“不同的开局”，不是独立重复的随机性，所以“5 / 5 同向”不能当作显著性检验来读。

**站得住的（方向一致、幅度大）：**

- **下雨是这组里对老人影响最大的一件事。** 去公园的人次掉了八成，茶馆只多了 15%，接不住；老人每天聊天从 5.7 次掉到 3.3 次，一整天没说上话的老人从 2% 升到 8%，新交的朋友也少了近一半。在这个模型里，老人的社交主要挂在露天的地方上。
- **传言自己把菜买空了。** 六个人起头，九天里传到了 79% 的人；人均存粮从 6 份涨到 10.7 份，菜市场营业额涨了三成多，五个种子里每天都有人白跑一趟。
- **食堂抢的是在家吃的饭，也抢了饭馆。** 饭馆营业额少了 15%，小超市也少了 9%（买菜少了）；在外面吃的顿数每天多了 16 顿。
- **菜市场关了，小超市接住了。** 营业额涨了四成，几乎没人白跑；原来担心的“买不到菜”在这个模型里没有发生，因为两家小超市每天补货的量加起来够。这一条取决于补货量这个参数，换个数字结论就会变。

**落空的，和它们说明的问题：**

- **老人并没有因为菜市场关门而少聊天（M3 相反），食堂也没有让“没说上话的老人”变少（C1 不明确）。** 和事先的直觉一致：模型里老人的聊天主要来自下棋、打牌、晒太阳，买菜和吃饭时的闲聊只占很小一部分；而一整天不说话的老人是不出门的那几位，一顿便宜的饭叫不动他们。现实里菜市场和食堂的社交功能可能比这大，模型把它低估了。
- **裁员后“上班的人”心情反而好了一点（L4 相反），花销也没少（L1 相反）。** 这正是事先担心的：模型里的心情只看吃饱、精力、社交、乐趣，没有“丢了工作”本身的分量；被裁的人更闲，去茶馆的人次还多了。三周里他们还有存款，也没有收紧开销。**这是模型缺的机制，不是发现。**
- **房租涨了，下馆子的人没有变少（T2、T3 相反，幅度不到 1%）；发钱让人多下馆子（V1–V3 支持），但每天只多 4 顿。** 钱对行为的传导太弱：房租、补贴都走家庭账户，个人只通过“手头紧不紧”这一项感到，而大多数家庭余额充足，这一项是零。

**下一步该补的（按重要性）：**

1. 钱到行为的传导：预算感（按月收入而不是按余额）、对未来收入的预期、丢工作之后的收紧。
2. 心情里要有处境的分量：失业、入不敷出、长期独处。
3. 用决策模型把这七个案例再跑一遍，看哪些结论两种心智都成立（旧版的规矩，新内核还没做到，见 v5 方案 D92）。
4. 对补货量、囤货系数这类直接决定结论的参数做敏感性分析。
